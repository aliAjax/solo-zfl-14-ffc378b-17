# 设备保养档案

端口规划：`5114`

```bash
npm install
npm run dev
```

面向住户的设备保养档案，数据只存浏览器 localStorage，刷新不丢失；读取异常回退空列表，保存失败不阻断页面。

- 设备档案：登记房间与设备（品牌、型号、启用时间、保养周期），同名房间/同设备不重复登记
- 首页提醒：按周期推算下次保养日，到期/逾期提醒，可登记已保养向后滚动
- 报修：问题、优先级、预计花费、计划完成日；同一设备同一未处理问题不重复生成
- 处理记录：维修人、起止时间、工时（自动计算）、耗材（名称/数量/单价）、结果；每个报修只保留一条记录
- 费用汇总：按月汇总每台设备的耗材花费

```bash
npm test        # vitest：档案/提醒/报修/处理记录/费用汇总/存储异常
npm run build
```
